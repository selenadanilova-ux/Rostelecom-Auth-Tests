# Автоматизация тестирования системы авторизации Ростелеком (B2C)
Данный проект содержит набор автотестов для проверки личного кабинета.

## 🚀 Стек технологий
* **Python** (язык разработки)
* **Selenium WebDriver** (управление браузером)
* **Pytest** (фреймворк для тестирования)
* **Page Object Model (POM)** (паттерн проектирования)
* **python-dotenv** (управление секретами)

## 📁 Структура проекта
* `docs/` — артефакты тестирования (тест-кейсы, баг-репорт, пояснительная записка).
* `pages/` — объекты страниц (локаторы и методы взаимодействия).
* `tests/` — тестовые сценарии (позитивные и негативные проверки).
* `settings.py` — конфигурация и управление тестовыми данными.
* `.env` — файл для хранения конфиденциальных данных (логины, пароли).

## 🛠 Установка и запуск
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd название-репозитория
2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для macOS/Linux
   .venv\Scripts\activate     # Для Windows
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
4. **Настройте переменные окружения:**
   Создайте файл .env в корне проекта и добавьте:
   ```text
   VALID_EMAIL=ваш_email
   VALID_PASSWORD=ваш_пароль
5. **Запустите тесты:**
   ```bash
   python -m pytest tests/
